# KPG @ GitHub Pages

Personal site of Krzysztof P. Gocek, served at <https://kpgocek.github.io>.

A single static page: plain HTML and CSS with no images, dependencies, or build steps. The only JavaScript is the theme toggle.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The page |
| `styles.css` | All styling, shared by both pages |
| `404.html` | Shown by GitHub Pages for any missing URL |
| `theme.js` | Dark/light toggle; dark unless the visitor picks light |
| `fonts/` | Self-hosted Instrument Serif and Plus Jakarta Sans (Latin subsets) and their licences |
| `_config.yml` | Site metadata; keeps `README.md` from being published |

## Deployment

GitHub Pages publishes the site from `main`, so pushing is all it takes.
